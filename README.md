# RAGを用いた機械学習結果の業務向け解釈PoC

## 概要
本プロジェクトは、**機械学習モデルの予測結果** と **RAG（Retrieval-Augmented Generation）** を組み合わせて、  
**非技術者にも伝わりやすい業務向けの説明文や示唆を生成する** ことを目的とした PoC（概念実証）です。

本プロジェクトでは、以下を実装しています。

- California Housing データセットを用いた住宅価格予測モデルの構築
- Markdown 形式の知識文書を用いた簡易RAG
- モデル結果に関連する知識の検索
- 検索結果を踏まえた、LLMによる業務向け説明生成

単に予測モデルを作るだけでなく、  
**モデル結果をどのように業務判断へつなげるか** に焦点を当てています。

---

## 背景
分析プロジェクトでは、モデルの精度そのものだけでなく、  
**その結果を事業部や現場が理解し、活用できるか** が重要です。

実際には、以下のような課題が起きやすいと考えています。

- モデル結果が非技術者に伝わりにくい
- 評価指標や特徴量重要度だけでは、業務でどう使うべきか判断しにくい
- データサイエンティストが毎回“通訳”のように説明する必要がある
- 会社固有の方針や過去知見が、結果解釈に十分反映されない

そこで本プロジェクトでは、  
**モデル結果に対して会社知識やヒアリングメモをRAGで付与し、業務文脈を踏まえた解釈を生成する**  
ことを試しています。

---

## 想定ユーザー
現時点では、主に以下のようなユーザーを想定しています。

- データサイエンティスト
- 分析担当者
- PoC担当者
- 分析結果を事業部向けに説明する必要がある人

現段階では Python スクリプトとして実装しているため、  
事業部が直接操作するツールというよりは、  
**分析担当者が事業部向け説明のたたき台を作るための支援ツール** という位置づけです。

---

## このPoCで確認したいこと
このプロジェクトでは、主に以下を確認することを目的としています。

- 機械学習モデルの結果に対して、RAGで会社知識を付与すると説明内容が変化するか
- 短い方針文書だけでなく、ヒアリングメモのような長めの文書も知識源として使えるか
- モデル結果を、非技術者が理解しやすい形へ変換できるか
- 分析結果を、業務上の注意点や次アクションに接続できるか

##  各ファイルの役割

### `src/ml_model.py`
California Housing データセットを用いて、LightGBM による住宅価格予測モデルを構築します。  
以下のような情報をまとめて、LLM に渡しやすい文字列として生成します。

- 評価指標（MAE, RMSE, R²）
- 重要特徴量
- 予測例

### `src/build_index.py`
`knowledge/` 配下の Markdown ファイルを読み込み、チャンク分割・embedding 生成を行い、  
RAG 用のインデックスを `data/index.json` として保存します。

### `src/rag.py`
作成済みの `index.json` を読み込み、クエリに対して意味的に近い知識チャンクを取得します。

### `src/ask_rag.py`
全体の実行スクリプトです。  
以下の処理をまとめて実行します。

1. 機械学習モデルの結果を生成する
2. 結果に関連する知識を RAG で取得する
3. 取得知識とモデル結果をもとに、LLM へ説明生成を依頼する
4. 業務向けの説明文を出力する

---

## 知識文書について
`knowledge/` 配下には、架空の社内知識文書を配置しています。  
現時点では、例えば以下のような文書を想定しています。

- 会社方針
- 営業向けガイドライン
- 顧客ヒアリングメモ

これにより、単なる一般論ではなく、  
**会社の方針や業務文脈を踏まえた説明** が生成されることを狙っています。

## 実行方法

### 1. ライブラリをインストール

```bash
pip install -r requirements.txt
```

### 2. APIキーを環境変数に設定

OPENAI_API_KEY を環境変数として設定してください。

### 3. インデックスを作成
```
python src/build_index.py
```
### 4. モデル構築 + RAG + 説明生成を実行
```
python src/ask_rag.py
```

## 現時点の実装範囲

現時点では、以下を実装済みです。

 - Markdown 文書を用いたローカル RAG
 - 段落ベースの簡易チャンク分割
 - embedding による類似検索
 - LightGBM による住宅価格予測
 - モデル結果と検索知識を組み合わせた説明生成
